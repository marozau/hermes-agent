Decompose the project into epics and user stories:

1. **Epics** — Major workstreams (3-5 per project depending on scope)
2. **User Stories** — For each epic: story title, description, acceptance criteria
3. **Story Mapping** — Phased delivery: MVP → growth → mature
4. **Dependencies** — Story-to-story and external dependencies

For each story include:
- Title and description (As a... I want... So that...)
- Acceptance criteria (Given/When/Then)
- Effort estimate (S/M/L)
- Priority (P0-P3)

Write to `planning-artifacts/epics-stories-{project_name}-{date}.md`.

Run a structured brainstorming session for the current project:

Use creative techniques to generate ideas:
1. **SCAMPER** — Substitute, Combine, Adapt, Modify, Put to another use, Eliminate, Reverse
2. **Brainwriting** — Generate ideas silently, then share and build
3. **Reverse Brainstorming** — How could we make the problem worse? Reverse the ideas

For each idea generated, capture:
- Idea name and brief description
- Potential impact (High/Medium/Low)
- Rough effort (S/M/L)
- Connection to project goals

Document the best ideas in `planning-artifacts/brainstorm-{project_name}-{date}.md`.

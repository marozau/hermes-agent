Validate the existing PRD for completeness and quality:

1. **Completeness Check** — Are all required sections present?
2. **Requirements Quality** — Are requirements testable, unambiguous, singular?
3. **Consistency Review** — Do sections align? No contradictions?
4. **Adversarial Review** — Challenge assumptions, find edge cases
5. **Editorial Review** — Structure, clarity, formatting

Check against the requirements quality checklist:
- [ ] Each requirement is singular (one capability)
- [ ] Testable (verifiable independently)
- [ ] Unambiguous (same interpretation by multiple readers)
- [ ] Non-functional requirements have measurable targets
- [ ] All edge cases documented
- [ ] States what is OUT of scope
- [ ] Dependencies identified

Report findings and required fixes to the user.

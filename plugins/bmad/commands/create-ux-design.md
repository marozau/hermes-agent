Create UX design documentation for the project:

1. **User Flows** — Key journeys through the product (entry → screens → decisions → exit)
2. **Screen Designs** — Wireframes for key screens and interactions
3. **Design System** — Design tokens, components, patterns
4. **Accessibility** — WCAG 2.1 AA+ compliance checklist
5. **Responsive Strategy** — Breakpoints, layout adaptations
6. **Interaction Patterns** — Animations, transitions, micro-interactions

For each user flow, document:
- Entry point and exit criteria
- All screens and decision points
- Error and edge case states

Write to `planning-artifacts/ux-design-{project_name}-{date}.md`.
